OUTLAST TRIALS [RU] — GitHub Pages

1. Создай на GitHub публичный репозиторий с именем: outlast-trials-ru
2. Загрузи index.html и папку assets целиком в корень репозитория.
3. Открой Settings → Pages.
4. В разделе Build and deployment выбери Deploy from a branch.
5. Выбери Branch: main и Folder: /(root), затем Save.
6. После публикации сайт будет иметь адрес:
   https://ТВОЙ-GITHUB-USERNAME.github.io/outlast-trials-ru/

ВАЖНО:
Открой index.html и замени оба вхождения YOUR-USERNAME на свой GitHub username:
- og:url
- og:image

После этого сохрани и закоммить изменения. Discord может кешировать старый предпросмотр.
Эта страница создаёт обычный предпросмотр ссылки (Open Graph), а не специальный интерактивный компонент Discord. Она не показывает автоматически число участников/онлайн и не встраивает настоящую кнопку вступления внутрь карточки предпросмотра. Кнопка на самой веб-странице ведёт на приглашение Discord.
